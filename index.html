The three-step onboarding path

Use this sequence to move a qualified prospect into Sazón. Registration establishes the operator’s account and subdomain; underwriting provides the payment credentials needed to complete payment configuration.

1

Start at Sazón

Open the public landing page and select Get Started.

2

Register the operator

Enter the restaurant name, agent email, and desired subdomain.

3

Complete credentials

After underwriting, enter the issued TPN and API/Secret Keys using the approved admin workflow.

Credential handling: TPNs, API keys, and secret keys are sensitive credentials. Do not place them in email, chat, public documents, or the Operator’s Guide. Use only the designated secure Sazón workflow.

Step 1

Navigate to the Sazón landing page

Begin with the main Sazón website. This is the prospect’s entry point for learning about the platform and beginning operator registration.

What to do

  1. Open sazon.cafe in a browser with the prospect.
  2. Briefly explain that Sazón combines online ordering, kitchen management, and payments.
  3. Select Get Started to open the operator-registration page.
Agent tip: Confirm the prospect has chosen a restaurant or operator name and a preferred website subdomain before continuing.

Step 2

Enter the operator’s registration information

The registration form creates the initial operator record and identifies the website subdomain for the business.

Complete the form

  1. Enter the restaurant or operator name exactly as the prospect wants it displayed.
  2. Enter the agent’s email address in Agent Email Address.
  3. Enter the desired website subdomain. The public restaurant link will use the format subdomain.sazon.cafe.
  4. Check spelling and confirm the subdomain with the prospect before proceeding.
  5. Select Begin Registration.

Good subdomain practice

  • Use the restaurant’s recognizable name.
  • Keep it short and easy to type.
  • Avoid spaces, punctuation, and unclear abbreviations.
  • Confirm availability before presenting it as final.

Agent registration checklist

  • Restaurant/operator name confirmed
  • Agent email verified
  • Subdomain confirmed with prospect
  • Registration submitted

Step 3

Add the TPN, API key, and Secret Key after underwriting

Once underwriting is completed, use the credentials issued through the approved payment-underwriting process to complete the operator’s payment configuration.

Before entering credentials

  • Confirm underwriting is complete and approved.
  • Verify that the credentials belong to the correct restaurant/operator.
  • Use the secure Sazón administrative location designated for payment credentials.
  • Do not share credentials in email, text message, screenshots, or public notes.

Credential-entry workflow

  1. Open the operator’s approved Sazón administrative configuration area.
  2. Enter the issued TPN exactly as provided.
  3. Enter the issued API Key exactly as provided.
  4. Enter the issued Secret Key exactly as provided.
  5. Save the configuration using the approved workflow.
  6. Confirm the configuration is associated with the correct operator before enabling or testing payments.
Important: A Secret Key should be treated like a password. If it is exposed or sent to an unintended recipient, follow your payment partner’s security procedure and rotate or replace the credential as necessary.

Next step

Assist the operator with profile setup

After registration and credential completion, help the operator configure their business profile, menu, locations, QR codes, orders, and sales workflow using the Sazón Operator’s Guide.

Open the Operator’s Guide

Use the guide with the operator to complete System Settings, Menu Items, Places and QR Codes, Menu Item Categories, Orders, and Order History.

Agent handoff checklist

  • Registration completed
  • Underwriting completed
  • TPN and API/Secret Keys entered securely
  • Operator directed to the Operator’s Guide
  • Operator profile and menu setup scheduled or completed
Recommended handoff: Stay with the operator through the first profile configuration session, then confirm the menu and QR code have been tested from a customer’s phone.
